# 文件批量处理

把一个混放文件的文件夹，按文件类型自动归类到 图片 / 文档 / 表格 / 压缩包 / 其他 子文件夹。

## 功能

- 遍历文件夹内所有文件，按后缀名自动分类
- 重名文件自动加序号，不会覆盖原文件
- 子文件夹保持不动
- 打印整理日志

## 使用方法

1. 打开 `文件批量处理.py`，在顶部 `TARGET` 填写要整理的文件夹路径；留空则整理脚本旁边的「演示文件夹」。
2. 运行：

```bash
py 文件批量处理.py
```

3. 回到目标文件夹查看分类结果。

## 自定义分类

修改脚本顶部 `CATEGORY` 字典即可，例如新增「音频」：

```python
'音频': ['.mp3', '.wav', '.flac'],
```

## 技术栈

Python · pathlib · shutil
